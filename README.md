# From Emotion to Expression: LLM-Driven Automatic Character Sprite Switching in Visual Novels

This repository provides the code and data for our experiments on automatic
character sprite switching in LLM-driven visual novels.

## Repository structure

- **`CodesForImage`** — code and generated images for the character expression sprites.
- **`experiment`** — all experiment prompts, the stories used, the running
  process, and the results.

## Unity runtime system

The Unity project used for the user study is provided via Google Drive:
**[VNSpriteSwitchProjectInUnity (Google Drive)](https://drive.google.com/file/d/1dfV-Afg5N08nVndDHTUERhLHGiESiJcW/view?usp=sharing)**. It is currently a rough
prototype in which the user study can be run inside Unity. The runtime in another scene requires
two OpenAI API keys to run.
For the setting guideline, you can check the previous version of this [VN system (Github Link](https://github.com/ZifanYE/UnityVNforGCCE).
